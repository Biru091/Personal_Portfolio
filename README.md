## Personal Portfolio

A modern, interactive personal portfolio website . The website combines a clean UI with smooth animations, 3D elements, and responsive layouts to create an engaging experience across desktop and mobile devices.

Built with modern web technologies, the portfolio highlights my frontend development skills, creative approach to UI/UX, and ability to build interactive and performance-focused web experiences.

### Features

* Modern and responsive design
* Interactive 3D elements
* Smooth GSAP animations and scroll-based interactions
* Skills and technology showcase
* About and contact sections
* Mobile-friendly experience
* Clean, reusable component-based architecture

**Tech Stack:** Next.js, React, TypeScript, Tailwind CSS, GSAP, Three.js,Lenis and React Three Fiber.
